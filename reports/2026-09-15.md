## 格局

**周期位置** 扩张第三年向第四年过渡的窄通道仍在。头部四家云厂季度 capex 合计稳在 900 亿美元上方, 但本期新 capex 上修仅英伟达锚定 Anthropic 一家, 环比斜率自前次转平后未现二次抬头; Anthropic 以六年期 137 亿美元锁定 Rum Group 佐治亚园区, 单笔金额已逼近头部云厂单季上修量级, 意味着订单集中度正向非超大规模客户侧迁移, 总盘子的边际增量未明显扩张。

**主线轨迹** 过去：晶圆制程产能 → **当下：HBM与CoWoS良率位元密度** → 未来：数据中心电力接入与机柜热密度

单卡功耗从 H100 的 700W 升至 GB200 的 2.3kW 量级, Vera Rubin 世代进一步上探, 液冷从可选项变为必选; 园区主变与燃机排期 18 至 36 个月与 GPU 供货周期形成数量级错位, 而 Rubin NVL72 推理每兆瓦 token 较 Blackwell 提升 7 倍, 凸显电力已取代芯片成为机柜级 PUE 的首要约束。

**切换信号** 若北美新建园区电力接入审批成为项目主要延迟项, 或单机柜功率密度普遍突破 130kW 并批量化交付

**盲区** 本库对几大核心标的长期依赖二手转述: 苹果近 30 天有 109 条相关信息, 但全部来自 sec_edgar 以外, 无一手 IR; Meta 72 条、ASML 34 条、ARM 17 条同样结构性缺位; Intel 52 条覆盖但 days_since_own_disclosure 为空; AMD 124 条中最近自有披露已 14 天, Marvell 29 条中 18 天未更新, 美光 115 条中 20 天, 超微 23 条中 15 天。意味着对 Rubin 出货指引、CoWoS 实际报价、MI400 客户结构、SMCI 与戴尔 AI 服务器订单的最新判断, 全部处于二手外推区间, 财报窗口前的方向性下注风险高于表观。

**本期检验** 今天的素材在两端同时拉扯这根轴。向上拉的是 E3 的 Rubin NVL72 推理每兆瓦 token 提升 7 倍, SemiAnalysis 用 1.6T DeepSeek 模型的实测指向黄仁勋 3 倍口径之下仍有藏性能, 若官方确认, 算力 ROI 与云厂 capex 斜率将上修; E2 的台积电 3nm/2nm 与 CoWoS 持续供不应求, 联发科因谷歌 TPU 大单争抢产能, 验证封装端仍属硬约束。向下拉的是 E13 与 E14 的减速论阵营, Amodei、Altman、Musk 同框呼吁 pace the frontier, 而黄仁勋当面向特朗普表态不会让 AI 放缓发生, 两套路线对短期景气指向相反结论; E8 的英伟达、Palantir 因数据安全缩减前沿模型使用, 进一步把需求从云端 API 推回本地推理, 与 E4 的 RTX PRO 5500 84GB GDDR7 下沉方向一致, 强化了边缘与本地化对冲云端 capex 的传导。

**较上期** 微调 —— 三段轨迹维持, now 段由 HBM/CoWoS 良率位元密度加电力热密度前置约束, 调整为 Agent 长任务落地叠加 CEO 同框放缓前沿, 推动训练侧周期与推理侧机柜密度的相对权重再分配

## 判断一 · Vera Rubin 推理能效藏性能, 机柜级电源与液冷价值量上修

**事实** SemiAnalysis 测得 Vera Rubin NVL72 在 1.6T DeepSeek 模型上每兆瓦 token 吞吐较 Blackwell 提升最高 7 倍, 高于黄仁勋此前 3 倍口径, 并强调大规模采购可获 2 倍年化每吉瓦利润。

**机理** 推理能效提升 7 倍的物理含义是单位 token 摊销的电力与机柜租金被压到原来的七分之一, 客户侧 ROI 拐点提前; 而 Rubin 把单机柜功率进一步推高, 800VDC 母线取代传统 54V 配电成为必须, 液冷从冷板式向浸没式过渡, 每机柜的 CDU、一次侧换热、电源转换价值量翻倍, 这是 GE Vernova、Schneider、台达、以及液冷板与冷媒供应商的订单起点。

**推论** 若 GTC 或法说会上黄仁勋修正 Rubin 性能指引, 卖方对台积电 CoWoS-L capex 与 2027 年北美园区主变排期将同步上修; 电源与液冷供应链是当前唯一可被订单数据提前验证的二阶传导。

**证伪条件** 若 2026Q4 台积电法说会下调 2027 年 CoWoS-L capex 指引, 或 GE Vernova 与 Schneider 电力业务订单同比增速回落至 20% 以下, 本判断失效。

**证据**

- [Vera Rubin NVL72 inference tests show up to 7x better token throughput per MW vs. Blackwell on a 1.6T DeepSeek model, above Huang's 3x claim for 1T-3T LLMs (Bryan Shan/SemiAnalysis)](https://www.techmeme.com/260914/p41#a260914p41) · Techmeme · 09-15 · 低可信

**反面** SemiAnalysis 属付费研究机构, 模型假设的批大小、精度、MoE 激活率未披露, 1.6T DeepSeek 为 MoE 架构, 7 倍增益无法外推到稠密模型; 推理能效提升反而压制总电力需求, 长期对电网侧是利好但对 capex 总量是负反馈。

## 判断二 · CEO 同框呼吁放缓前沿, 反而锁定美国阵营算力加速路径

**事实** Amodei、Altman、Musk 同框主张 pace the frontier, 微软同步发布 2027 年前模型行为准则, OpenAI 宣布今年不上市; 与此并行, 黄仁勋当面向特朗普表态不会让 AI 放缓发生, Anthropic 仍以 137 亿美元六年长租锁定 Rum Group 佐治亚园区。

**机理** 减速共识若成立, 训练侧 H200/B200 集群扩张窗口被压缩, 但 Anthropic 长租与黄仁勋表态说明头部算力链并未按减速论排产, 物理上是训练集群的折旧周期仍在 3-5 年, 已部署的 Rubin 与 Blackwell 必须在推理端消化, 这就把算力需求从训练 capex 迁移到推理 token 消耗, 而 token 消耗按当前 ARR 增速外推仍支撑 capex 高位。

**推论** 短期看英伟达、AVGO、台积电订单预期受减速叙事扰动, 但只要 Anthropic 与 OpenAI 任一公开训练集群 capex 不下修 10% 以上, 算力链高景气延续, 反而是 OpenAI Jalapeño 这类自研芯片对英伟达训练侧份额构成二阶压制, 需在 2026Q4 验证。

**证伪条件** 若 2026Q4 Anthropic 或 OpenAI 任一公开训练集群 capex 下修超 10%, 或独立评估者仅获模型访问而无权重与训练数据审计权限, 本判断失效。

## 判断三 · 先进封装与 HBM 仍是 2026Q4 前最硬的供给侧约束

**事实** 台积电 3nm/2nm 与 CoWoS 持续供不应求, 英伟达与苹果占据主要产能份额, 亚马逊 AWS 旗下 Annapurna 获更多 3nm 产能, 联发科因谷歌 TPU 大单争抢 2/3nm 制程与 CoWoS-S/L 产能。

**机理** CoWoS-L 的良率受中介层翘曲与 RDL 对位精度限制, 单次封装良率提升斜率已显著放缓, 任何追加订单都要靠更多晶圆投入来换, 这就封死了 2026Q4 前云厂 AI 服务器出货的天花板; 同时 AMD 披露的 3D DRAM 通过 Cu-Cu 混合键合绕开微凸块, 17 倍能效提升若量产, 将打开 HBM 之外的第二条存储赛道, 短期对海力士形成替代叙事压制, 长期削弱三大原厂定价权。

**推论** 台积电订单可见度延伸至 2027-2028 年确定性强, HBM 端短期仍是海力士主导, 但 3D DRAM 在 AMD 路径上的进展意味着 2027 年后存储价值链可能重切; 北方华创在 64 层 Si/SiGe 刻蚀上达到 95% 均匀度, 国产 DRAM 产线 2-3 年内有望摆脱美日荷设备依赖。

**证伪条件** 若 2026Q4 CoWoS 报价环比回落超 5%, 或 AMD 3D DRAM 流片良率连续两个季度低于 50%, 本判断失效。

- [DRAM的下一个十年，要“站起来”](https://www.tmtpost.com/8139412.html) · 钛媒体 · 09-15 · 二手

**反面** 若黄仁勋确认 Rubin 7 倍能效成立, 同样 token 需求下 GPU 出货量可压缩, 反向缓解 CoWoS 紧缺, 当前供不应求局面可能在 2027H2 出现拐点。

## 判断四 · Token 变现开始覆盖训练摊销, 推理 capex 锚向非超大规模客户迁移

**事实** Anthropic 连续两季盈利, 调整后毛利率超 80%, 寻求 Nasdaq 挂牌; ARR 从 2025 年底约 90 亿美元升至 2026 年 7 月底约 650 亿美元, 推理 token 三个月增 1.5 倍; 同时以 137 亿美元六年长租锁定 Rum Group 佐治亚园区。

**机理** 高客单价订阅与 API 调用已能覆盖训练摊销, 这意味着模型公司的资本开支周期不再依赖一级融资, 而是锚向 ARR 增速, ARR 6-7 倍年化对应 token 消耗数倍年化, 反推推理算力需求曲线斜率; 智谱在天猫将 Token 套餐标准化销售, 2026H1 云端 API 收入暴增 2735.7%, 验证 ToB 与 ToC 两条变现通道同时打开。

**推论** Anthropic 的长租对戴尔与超微构成直接订单增量, 而非超大规模客户锁定算力意味着 CoWoS 与 HBM 的客户结构从四家云厂向更多长尾 AI 公司分散, 对台积电 ASP 是中性偏多; 但若 Anthropic S-1 披露盈利大量依赖递延收入与一次性调整项, 整个 token 变现叙事需要重估。

**证伪条件** 若 2026Q4 Anthropic 或 OpenAI 任一公开训练集群 capex 上修超 10%, 或 Anthropic 递交 SEC 的 S-1 披露其盈利口径大量依赖递延收入与一次性调整项, 本判断失效。

## 张力与联动

四条判断的内核是一对错位: 能效提升 7 倍本应压缩 capex 总量, 但 token 变现又把它重新撑起。Rubin 性能超指引利好 NVDA 短期, 但若 token 单价继续下行, 客户侧 ROI 拐点会把算力订单从训练集群迁移到推理集群, 而推理侧的机柜密度与电力约束远比训练侧更刚性, 这意味着 2027 年的瓶颈不在芯片也不在 HBM, 而在园区主变与燃机排期。同时 CEO 同框减速与黄仁勋当面反向表态的并置, 把政策不确定性这条暗线摆到台面, 任何美国侧实质性的训练 capex 下修都会同时证伪第二条与第四条判断, 而第三条封装约束与第四条 token 变现之间存在客户结构迁移的张力, 需在 2026Q4 用 CoWoS 报价与 Anthropic S-1 同时验证。
