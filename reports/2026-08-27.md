> 英伟达订单与长协共振,算力锁定从季度采购升级为多年产能预占

## 格局

**周期位置** 扩张第三年向第四年过渡,头部四家云厂季度 capex 合计仍维持 900 亿美元以上、同比扩张 40% 以上,本季环比斜率首次转平;同期阿里单季资本开支 676.78 亿元、同比 75%,远超市场预期 360 亿元,中美头部已共同进入营收兑现与回本框架约束并行的阶段

**主线轨迹** 过去：晶圆制程产能 → **当下：HBM 容量与 CoWoS 双约束** → 未来：单机柜功率与电力接入

B200/Rubin 单卡功耗跨过 1kW 之后,3D 堆叠结构下热量需穿过多层介电层,介电层导热率与封装热密度取代光刻精度成为良率主约束,CoWoS 又被 Google TPU、AMD MI 系列、博通 ASIC 多线争抢,味之素 ABF 基板对华削减 30% 供货进一步推高边际成本

**切换信号** 若单机柜功率密度普遍突破 130kW,或北美超大规模园区电力接入审批成为交付主延迟项,即视为算力主约束完成向电力段的迁移

**盲区** 覆盖盲区集中在产业链中游的关键节点。台积电近 30 天有 354 条相关信息进入本库,但 level 仍标记为 structural 且无自有披露,意味着对其 N2 稼动率与 CoWoS 排期的判断只能依赖二手转述与同业外推;ASML 近 30 天 124 条、博通 231 条、ARM 82 条,同样无任何一条来自其自有披露通道,意味着 EUV 出货、ASIC 客户结构、CSS 营收节奏三个高敏感变量的当前状态,本库无法独立验证。存储一侧,海力士、三星、美光在 coverage_audit 中完全缺席,无法独立判断 HBM3e/4e 实际配额分配与 DRAM 业务 ASP 走势,本期只能以英伟达订单侧的信号做间接外推。算力锁定模式已从季度采购升级为多年产能预占,但 Nscale 这类专业级 GPU 云的角色从'转售'向'自营 capex 承担方'迁移,叠加英伟达 5000 亿美元级融资平台的风险承担方尚未明确,构成对供应链信用传染的二阶不确定性

**本期检验** 本期素材在三条线上同时强化了 now 段的判断。订单侧,Vera Rubin 全面投产叠加客户承诺订单由 1190 亿翻倍至 2790 亿美元、环比扩张 135%,把封装与 HBM 的紧缺从季度窗口拉长到 2027-2028 的多年维度;部署侧,AWS 在 2027-2028 年累计 300 万颗 GPU 的采购承诺、Anthropic 与 Nscale 六年 450 亿美元长协租用 460MW 容量,以及印度 AM Intelligence 9000 套系统对应 1GW 算力,把算力扩张的物理形态从机柜级推向园区级与 GW 级,意味着 CoWoS 与 HBM 的供给曲线短期内无法匹配需求曲线。算力经济学侧,Vera Rubin NVL72 在 Agent 推理工作负载下每兆瓦吞吐最高 30 倍于 GB300 NVL72,显示单位 token 能耗正在快速下行,这一能效跃迁正是 Qwen3.8-Flash 把推理价压到每百万 token 输入 1 元/输出 3 元的物理基础,也是模型层做'价'与算力层做'量'两条叙事得以同时成立的原因。框架尚未被本期证据证伪,但 NVHBM + NVLink Fusion 通过定制 base die 反向定义 HBM 标准,意味着英伟达正把供给约束从'产能'升级为'规格主导权',这一变量已超出当前 now 段的描述范围,需要在下一次微调中纳入

**较上期** 微调 —— 维持晶圆-封装-电力三段轨迹,但在 check 段正式将电力从 next 预备段升格为 now 待溢出段,并新增 AVO 对智能体中间层价值链的判断

## 判断一 · 算力锁定从季度采购升级为多年产能预占,长协与租赁双轨加速,封装与 HBM 紧缺周期被订单结构刚性延长

**事实** 英伟达宣布 Vera Rubin 全面投产,客户承诺订单由 1190 亿升至 2790 亿美元、环比扩张 135%;AWS 2027-2028 年累计 300 万颗 GPU;Anthropic 与 Nscale 六年 450 亿美元长协租用 460MW;印度 AM Intelligence 订购 9000 套系统对应 1GW 算力

**机理** 当订单从单季度 1190 亿翻至 2790 亿、且同时把交付窗口拉长到 2-3 年,台积电 CoWoS 排产就被锁定为多年刚性需求,海力士/美光的 HBM3e/4e 产能配额随之被预占,新进入者无法在窗口期内通过追加资本开支改变供给曲线,封装与存储的议价权从'季度博弈'转为'多年合约'

**推论** CoWoS 紧缺周期被订单结构刚性延长,直接利好台积电与 ABF 基板链;HBM 紧缺通过产能虹吸向通用 DRAM 传导,海力士、美光、三星进入强势议价周期;超微电脑、戴尔作为机柜级系统集成商,在长协模式下议价权弱于英伟达但订单可见度提高

**证伪条件** 若 2026Q4 台积电 CoWoS 月产能未达到 7.5 万片、或 2027H1 头部云厂 GPU 实际交付量低于承诺订单的 70%,本判断失效

## 判断二 · 英伟达从卖 GPU 转向卖系统,Agent 推理的异构堆栈把定价权从单卡延伸至机柜级全栈

**事实** Hot Chips 2026 披露 Vera Rubin NVL72 在 Agent 推理工作负载下每兆瓦吞吐最高 30 倍于 GB300 NVL72,关键变化在于将推理拆分为 Vera Rubin NVL72、Groq 3 LPX、Vera CPU、Spectrum-X 的协同架构;NVHBM + NVLink Fusion 通过定制 base die 反向定义 HBM 标准

**机理** 在 Agent 推理负载下,中位输入超 14 万 token 且涉及多轮工具调用,纯 GPU 推理的能效边界迅速逼近;将低延迟 token 生成卸载到 Groq 3 LPX、把编排层放到 Vera CPU、由 Spectrum-X 承担节点间互联,单位 token 的总成本下降 30 倍意味着单机柜可服务更多并发用户,系统级 ASP 的扩张空间不再受单卡价格约束,而是按机柜价值量定价

**推论** 英伟达通过 NVHBM 定制 base die 与 PHY 反向定义 HBM 标准,把供给侧的规格主导权与需求侧的能效基准同时握在手中,海力士、美光、三星被迫接受定制化;Vera CPU + SOCAMM2 切入 agentic 编排层,全栈粘性从 GPU 延伸至 CPU 维度,ASIC 路径的替代威胁被系统级绑定部分对冲;AMD MI400 必须在能效与生态两个维度同时证明独立价值,否则只能在英伟达配额之外争取增量

**证伪条件** 若 2027Q1 头部四家云厂公布的 AI 服务器系统实际签单价低于英伟达涨价后报价的 5% 以上,或 AMD MI400 量产版在 2026Q4 拿到独立于英伟达配额之外的 HBM4 长协,本判断失效

**证据**

- [英伟达Vera Rubin的Agent吞吐暴涨最高提升30倍，却不只靠GPU | Hot Chips 2026](https://www.leiphone.com/category/chips/liubrhlszczlyhwv.html) · 雷锋网 · 08-26 · 二手
- [英伟达称Vera Rubin已全面投产](https://36kr.com/newsflashes/3957001849044355?f=rss) · 36氪 · 08-26 · 二手

**反面** 30 倍能效提升系英伟达自测数据,使用 SemiAnalysis AgentX 与 DeepSeek V4-Pro 这一特定组合,生态外模型能否复现未被披露;Groq 3 LPX 是收购资产,客户是否接受非纯 GPU 堆栈仍需在 2027 年实际部署中验证

## 判断三 · 模型层做价、算力层做量,两条叙事同时成立但通过能效曲线耦合,中游价值正在向智能体中间层迁移

**事实** 阿里发布并开源 Qwen3.8-Flash,采用 125B 激活 6B 的 MoE 架构,训练成本较 Qwen3.7-Plus 降 90%,推理价每百万 token 输入 1 元/输出 3 元,仅为 DeepSeek-V4-Flash 的 1/3;同窗口内英伟达订单翻倍、长协规模刷新历史

**机理** Qwen3.8-Flash 的低价并非来自补贴,而是来自 MoE 激活参数压到 6B 后单位 token 算力消耗的物理下降;Vera Rubin NVL72 在 Agent 负载下每兆瓦吞吐 30 倍提升,把单位算力供给曲线也向右平移;两条曲线在能效轴上同向运动,使'量'与'价'得以在两个不同环节同时扩张,前者做 token 调用量、后者做机柜价值量

**推论** 模型公司之间的竞争从'能力比拼'转向'每 token 成本比拼',开源低价 Flash 模型加速行业商品化,自部署替代云端 API 是长期趋势;但商品化反而扩大了 token 调用总量,英伟达推理侧算力需求受二阶压制有限;价值链中游的智能体编排与工具调用中间层成为新的利润池,具备中间件与编排能力的标的具备相对阿尔法

**证伪条件** 若 Qwen3.8-Flash 在 30 天内 API 调用份额未进入全球前五、或头部四家云厂推理 capex 占总 capex 比重从当前水平下行超过 5 个百分点,本判断失效

**反面** 自评基准存疑,MoE 激活参数与稠密模型不可直接对比,复杂任务幻觉率与长上下文稳定性未被披露;低价开源反噬云收入,下游客户自部署替代阿里云 API 调用,长期或侵蚀云 AI 收入而非拉动

## 张力与联动

三条判断的内在张力集中在第二与第三条之间。英伟达把定价权从 GPU 升级为系统级,意味着每机柜价值量上行;但 Qwen3.8-Flash 代表的单位 token 算力消耗快速下行,意味着同一美元支出能购买的 token 数指数级增长,两者在英伟达营收上能否同时兑现,取决于 Agent 推理的实际 token 调用量是否随能效提升同比例甚至超比例扩张。第一条判断的多年长协锁单,锁住的是美元金额而非 token 数量,如果模型层的能效跃迁速度超过 Agent 场景的 token 增长曲线,长协名义金额与实际算力消耗之间会出现剪刀差,这是当前框架尚未捕捉的二阶风险
